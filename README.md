# How to use Zustand with Bryntum Gantt in React

 Demo of a custom assignee badge rendered inside a Bryntum Gantt column. The `main` branch shows how external React state changes don't re-render the badge. The `zustand` branch shows the fix.

## Install dependencies

Run the following command to install the project dependencies:

```bash
npm install
```

⚠️ You need a Bryntum licence to install the Bryntum dependencies. If you don't have one, install the [trial packages](https://bryntum.com/products/gantt/docs/guide/Gantt/integration/javascript/multiple-products).

## Run the development server

Run the Vite development server:

```bash
npm run dev
```

The server will start on `http://localhost:5173`.
